01 AI / GENERATIVE AI

DocMind AI — Intelligent Document Question Answering System

Python RAG - Retrieval-Augmented Generation FastAPI FAISS Sentence Transformers Hugging Face LangChain (sentence-transformers/all-MiniLM-L6-v2) DeepSeek (deepseek-ai/DeepSeek-V4-Flash-0731) PyMuPDF HTML CSS JavaScript REST API

DocMind AI is a Retrieval-Augmented Generation (RAG) based document Q&A system that allows users to upload PDF documents and ask questions about their content. The system extracts and splits document text into chunks, converts them into embeddings, stores them in FAISS, retrieves relevant information for a user query, and uses the DeepSeek model to generate a contextual answer.

PROJECT LINK
WHY

Students and professionals often have to search through lengthy PDF documents to find specific information. I wanted to build a system that could understand uploaded documents and provide relevant answers directly through a simple chat interface.

PROBLEM

aditional document reading requires manually searching through pages, and general-purpose AI models may not have access to the specific information contained in a user's private PDF. This makes it difficult to get accurate, document-specific answers quickly.

SOLUTION

I built DocMind AI with RAG, where users can upload a PDF and ask questions about its content. The system extracts and chunks the document, converts the chunks into embeddings, stores them in FAISS, retrieves the most relevant information for each query, and provides that context to the DeepSeek-V4-Flash-0731 model to generate a relevant answer.

03 Machine Learning

Movie Recommendation System using Machine Learning

Python Streamlit Pandas Numpy Scikit-Learn NLTK Pickle

Engineered a content-based recommender system using NLP and cosine similarity to suggest movies based on user input. Applied text vectorization (CountVectorizer) and built similarity matrix for 5000+ movies. Developed a real time recommendation interface using Streamlit, enabling dynamic movie suggestions. Implemented end-to-end ML pipeline from EDA - text preprocessing - vectorization - model persistence - deployment.

PROJECT LINK
WHY

With thousands of movies available, users often spend a lot of time deciding what to watch. I wanted to build a system that could recommend movies based on the user's interest in a particular movie.

PROBLEM

A user may like a particular movie but finding other movies with similar content can be difficult. Manually searching through thousands of movies is time-consuming and may not provide relevant recommendations.

SOLUTION

I built a content-based movie recommendation system using NLP and cosine similarity. Movie information was converted into numerical vectors using CountVectorizer, and a similarity matrix was created for 5,000+ movies. When a user selects a movie, the system compares its content with other movies and recommends the most similar ones through a Streamlit interface.

04 App Development

JobGallery — Work Photo Management App

Java Android Studio XML CameraX Android Storage API Gradle

Developed an Android-based work photo management application that enables users to capture and manage job-related images directly within the app, keeping them separate from personal gallery photos. Implemented in-app camera functionality using **CameraX**, handled image capture and storage using the **Android Storage API**, and created the application interface with **XML layouts** and **Java**. Designed app-specific storage to maintain separation of work images from the device’s personal media gallery and provide quick access to captured work.

PROJECT LINK Currently in Developing Stage
WHY

I developed JobGallery to solve a common problem faced by workers and professionals who take photos of their completed work to show customers. The idea was to provide a dedicated space for work photos, so they could easily access and present their work without exposing personal photos from their phone gallery.

PROBLEM

Workers often use their phone's normal camera and gallery to capture work photos. When they show these photos to a customer, their personal photos may also be visible, making it difficult to keep work and personal images separate.

SOLUTION

I developed JobGallery, an Android application where users can capture work photos directly inside the app. The captured images are stored in app-specific storage and accessed within the application, keeping them separate from the device's personal gallery. This provides a dedicated and organized way to capture, manage, and present work-related photos.
